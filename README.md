### 📘 Descripción General

Este repositorio contiene los reportes de incidencias y las evidencias documentadas durante las jornadas de prueba realizadas a los diferentes observatorios. Su propósito es registrar los hallazgos encontrados para su posterior revisión por parte del equipo de desarrollo.

> [!NOTE]
> Este repositorio es exclusivamente documental. No contiene código fuente, scripts de automatización ni modificaciones directas a los sistemas evaluados.
